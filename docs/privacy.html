Shabbat Mode — Privacy Policy

Last updated: April 25, 2026

Shabbat Mode is a Garmin Connect IQ watch face. This policy explains what data the app handles. The short version: nothing.

What we collect

The app collects, stores, and transmits no user data of any kind.

What permissions the app requests

None. The app's manifest.xml declares an empty permissions list. It does not access:

  • Heart rate, pulse oximeter, or any physiological sensor
  • GPS or location
  • Activity tracking (steps, floors, sleep, etc.)
  • Bluetooth, Wi-Fi, ANT+, or any communication channel
  • Calendar, contacts, notifications, or stored data

Network communication

The app does not make any network requests. It runs entirely on the watch.

Third parties

No analytics, no telemetry, no advertising, no third-party SDKs.

Source code

Source code is available on request to verify these claims.

Contact

Questions? Email noamshi@wix.com.
